Migrated all inline event handlers (onclick, onsubmit, onchange) to a new external CSP-safe JavaScript file (board-events.js) using addEventListener delegation. The board page, email detail actions, batch-op confirm dialogs, settings panel, and account picker now work under strict Content-Security-Policy (default-src 'self') without requiring 'unsafe-inline'. Inline handlers were replaced with data-confirm attributes on forms, and the shared board chrome continues to use the robotsix-board library.
