Accept same-origin form POSTs that report `Origin: null`. The server sends `Referrer-Policy: no-referrer`, and Firefox then withholds the real origin on form submission — so the add-account form rejected its own submission with "Forbidden: cross-origin request rejected". The CSRF guard now consults `Sec-Fetch-Site`, which the browser sets and a cross-site page cannot forge; a sandboxed cross-site POST carrying `Origin: null` is still rejected.
