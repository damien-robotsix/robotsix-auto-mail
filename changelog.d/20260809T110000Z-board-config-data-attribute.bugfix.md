Carry the board's JSON configuration in a `data-board-config` attribute instead of a `<script id="board-config" type="application/json">` block. The block is a data carrier that is never executed, but Firefox applies `script-src-elem` to any `<script>` element, so this server's own Content-Security-Policy logged a violation for it on every board load — a permanent console error that looked like a broken script while nothing was broken. `board-auto-mail.js` reads the attribute and falls back to element text for boards rendered by an older `robotsix-board`.
