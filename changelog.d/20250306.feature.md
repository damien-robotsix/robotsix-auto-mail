Add archive message listing and archive move endpoints.

- `GET /archive/<folder>/messages` returns envelope metadata (uid, subject, from, date, size, flags) for messages in an archive subfolder, with optional `?limit=N` cap.
- `POST /archive-move` relocates a message between archive subfolders via IMAP, with validation that paths stay under the archive root and lazy target-folder creation.
- `fetch_envelopes()` IMAP primitive and inline FETCH attribute parsers for envelope-only retrieval.
- Both endpoints documented in the chat-skill document; move endpoint gated behind operator confirmation.
