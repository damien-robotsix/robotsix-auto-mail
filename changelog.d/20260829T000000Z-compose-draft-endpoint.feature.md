POST /compose-draft endpoint for composing a reply or new outgoing message with file-hub attachments; the message is APPENDed into the target account's IMAP Drafts folder for native review and manual send from the user's mail client. Errors: 400 (invalid fields), 404 (unknown account/attachment), 502 (file-hub unreachable), 503 (file-hub not configured). Documented in chat-skill as confirmation-gated.
